PDDL-1.0. Dependencies remain under their upstream licenses. See LICENSE,
NOTICE, THIRD-PARTY.md, LICENSE-CHOICES.md, and SOURCE-OFFER.txt in this bundle.

  ammonia in the contribution backend. Full MPL text is in MPL-2.0.txt and
  source availability is in SOURCE-OFFER.txt.
* Lightning CSS — MPL-2.0 in web/mobile build graphs. Source availability is in
  SOURCE-OFFER.txt and exact package/source metadata is in the CI SBOM.
* ICU/Unicode and webpki-roots — Unicode-3.0/CDLA-Permissive-2.0 terms; exact
  package notices are retained by the generated CI inventory.
* Mobile Sharp/libvips — LGPL terms in development-only asset tooling; not

The CI license inventory enumerates every resolved npm and Cargo package from
all repository lockfiles, including development-only packages. Final container
SBOMs are generated in release CI. This concise bundle is not a substitute for
upstream copyright notices retained by that generated inventory.
